# StrawVerse Community Extensions (@cyber-winner)

Custom extensions repository for [StrawVerse](https://github.com/TheYogMehta/StrawVerse) featuring **Cinejoy** (Movies & TV Shows) and **AnimeSalt** (Multi-Language Dubbed Anime).

---

## 📦 Included Extensions

| Extension | Category | Version | Description |
|---|---|---|---|
| **Cinejoy** | Anime / Movies | `v1.0.0` | High-quality Movies & Web Series with multi-server resolution and subtitles |
| **AnimeSalt** | Anime | `v1.0.1` | Hindi, Tamil, Telugu, Malayalam, English, and Japanese multi-audio dubbed anime streams |

---

## 🚀 How to Add This Repository to StrawVerse

1. Open **StrawVerse**.
2. Go to **Settings** > **Marketplace** (or the Extensions tab).
3. Click **+ Add Repo**.
4. Enter this repository URL or raw marketplace link:
   ```text
   https://github.com/cyber-winner/EXTENTIONS
   ```
5. Install **Cinejoy** and **AnimeSalt** with one click!
